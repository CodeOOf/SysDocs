# SysDocs Example Test Files

This directory contains example project files for testing SysDocs functionality.

## Directory Structure

```
examples/
├── adns-project/           # Test input files (entire folder can be used as input)
│   ├── *.md                # Markdown documents
│   ├── *.tex               # LaTeX documents  
│   ├── *.txt               # Plain text documents
│   ├── *.csv               # CSV data files
│   ├── *.json              # JSON data files
│   ├── *.xml               # XML files
│   ├── images/             # Image files (SVG)
│   └── FORMAT_TEST_GUIDE.md
├── expected-results/       # Expected PDF outputs for byte-for-byte verification
│   ├── individual/         # Expected PDFs from individual file tests
│   └── folder/             # Expected PDF from entire folder test
├── TEST_PLAN.md           # Comprehensive test plan
└── README.md              # This file
```

## Test Approach

### 1. Test Input: `adns-project/`

The entire `adns-project/` directory serves as test input. It contains:
- **Diverse file formats**: Markdown, LaTeX, plain text, CSV, JSON, XML, SVG
- **Complete SE project**: ADNS (Autonomous Drone Navigation System)
- **Varied complexity**: 60-800 line documents, simple to complex tables, equations, diagrams
- **SE standards compliance**: INCOSE, IEEE, ISO standards

The folder can be used in two ways:
1. **Individual file tests**: Test specific format support (FR-01)
2. **Folder-level test**: Test processing entire directory (integration test)

### 2. Expected Results: `expected-results/`

Contains **actual PDF files** generated by SysDocs for byte-for-byte verification:
- `individual/01_markdown.pdf` - From single Markdown file
- `individual/02_latex.pdf` - From single LaTeX file
- `individual/03_plaintext.pdf` - From single plain text file
- `individual/04_csv.pdf` - From single CSV file
- `individual/05_json.pdf` - From single JSON file
- `individual/06_xml.pdf` - From single XML file
- `individual/07_mixed.pdf` - From multiple format files
- `folder/complete.pdf` - From entire `adns-project/` folder

### 3. Verification Method

Tests compare generated PDFs against expected PDFs using **SHA256 hash comparison**:

```bash
# Generate output
sysdocs --input examples/adns-project/12_SRS_ADNS.md --output test.pdf

# Compare hashes (byte-for-byte)
sha256sum test.pdf examples/expected-results/individual/01_markdown.pdf

# Hashes must be IDENTICAL
```

This verifies:
- **FR-06**: Deterministic output (same input → identical output)
- **NFR-01**: Reproducible builds
- **FR-14**: Cross-platform consistency (Linux, Windows, macOS produce identical output)

## Quick Start

### Generate Expected Results (First Time)

```bash
# Individual format tests
sysdocs --input examples/adns-project/12_SRS_ADNS.md \
        --output examples/expected-results/individual/01_markdown.pdf

sysdocs --input examples/adns-project/21_SDD_ADNS_Software.tex \
        --output examples/expected-results/individual/02_latex.pdf

# ... (see TEST_PLAN.md for complete list)

# Folder test
sysdocs --input examples/adns-project/ \
        --output examples/expected-results/folder/complete.pdf
```

### Run Tests

Tests compare generated output against expected results (byte-for-byte):

```bash
# Manual verification
sysdocs --input examples/adns-project/12_SRS_ADNS.md --output test_output.pdf
sha256sum test_output.pdf examples/expected-results/individual/01_markdown.pdf

# Automated tests (when implemented)
pytest tests/test_formats.py -v
pytest tests/test_folder_input.py -v
pytest tests/test_determinism.py -v
```
